# Download-images-from-1C
.EXE file to mass download images from 1C via .XLS/.XLSL file lists

**Как скачать изображения по ссылкам из Excel с помощью ImageDownloader**

Шаг 1. Помещаем файл программы ImageDownloader в удобную папку. Папка может быть любой, но лучше создать отдельную пустую папку специально для этой задачи – так будет проще ориентироваться.

Шаг 2. В ту же папку сохраняем файл Excel, содержащий ссылки на изображения, которые нужно скачать.

Шаг 3. Запускаем ImageDownloader.
При первом запуске Windows может показать предупреждение системы безопасности (SmartScreen) с кнопками «Не запускать» и «Подробнее». Нажимаем «Подробнее», затем – «Всё равно выполнить».
Если в папке находится несколько файлов Excel, программа предложит выбрать, с каким из них работать.

Шаг 4. Программа автоматически создаёт подпапку Downloaded_Images (если её ещё нет) и сохраняет все скачанные изображения в неё.

Важно (при ручном внесении изменений в файле). Списки товаров выглядят как файлы Excel, но на самом деле являются HTML-страницами, сохранёнными с расширением .xls / .xlsx. Если открыть такой файл в Excel, внести изменения и нажать Ctrl+S, он сохранится в формате веб-страницы, и программа не сможет его прочитать. Чтобы этого избежать, сохраняйте файл через «Файл» → «Сохранить как» и в поле «Тип файла» выбирайте «Книга Excel» (вместо стоящего по умолчанию варианта «Веб-страница»).
